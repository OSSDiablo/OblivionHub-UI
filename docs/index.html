Step 1

Load the library

Put this line at the very top of your script. It downloads Oblivion and gives you the Oblivion table you use for everything else.

local Oblivion = loadstring(game:HttpGet("https://raw.githubusercontent.com/OSSDiablo/OblivionHub-UI/main/Source.luau"))()
Step 2

Make a window

The window is your menu. Give it a name and the key that hides it.

local Window = Oblivion:CreateWindow({
    Name = "My Hub",
    Subtitle = "v1.0",
    ToggleUIKeybind = "RightControl",
})

Run it and you already have a working menu with Server, ESP and Settings tabs, plus the round Oblivion button that hides and shows it.

Moving and resizing. Drag any empty spot to move the menu. Drag the bottom-right corner to resize it.
Step 3

Add a tab

Tabs are the buttons in the sidebar. Each one has its own page.

local Main = Window:CreateTab({ Name = "Main", Icon = "zap" })

Step 4

Add elements

Elements are the buttons, switches and sliders inside a tab. They all work the same way: a Name, and a Callback that runs when the user uses it.

Main:CreateSection("Player")

Main:CreateButton({
    Name = "Say hi",
    Callback = function()
        print("hi")
    end,
})

Main:CreateToggle({
    Name = "Auto sprint",
    Callback = function(Value)
        print("Auto sprint is", Value)
    end,
})

Show a notification

A small card that pops up in the bottom-right corner and goes away on its own.

    Content = "Everything is ready",
    Type = "Success", -- "Info", "Success", "Warning" or "Error"
    Duration = 4,

Step 6

Save the user's settings

Three things: turn saving on in the window, give each element a Flag (a unique name), and call LoadConfig at the very end.

local Window = Oblivion:CreateWindow({
    Name = "My Hub",
    ConfigurationSaving = { Enabled = true, FolderName = "MyHub" },
})

local Main = Window:CreateTab({ Name = "Main", Icon = "zap" })

Main:CreateToggle({
    Name = "Auto sprint",
    Flag = "AutoSprint",
    Callback = function(Value) end,
})

Window:LoadConfig() -- always last
Why last? Loading needs every element to exist first, so it knows where the saved values go.

Keybind

Lets the user pick a key. Your callback runs when they press it. Click the key chip and press a new key to change it, Backspace clears it.

Main:CreateKeybind({
    Name = "Sprint",
    CurrentKeybind = "LeftShift",
    Mode = "Hold",                -- "Press" (default) or "Hold"
    Callback = function(Held)
        print("Sprinting:", Held)
    end,
})

Element

Change elements later

Every element gives you back a handle. Keep it in a variable to change the element from your code.

local Speed = Main:CreateSlider({ Name = "Walk speed", Range = { 16, 100 } })

Speed:Set(50)               -- change the value
print(Speed:Get())          -- read the value
Speed:SetTitle("Speed")     -- rename it
Speed:SetLocked(true)       -- lock it
Speed:SetVisible(false)     -- hide it
Speed:Destroy()             -- remove it

To lock an element from the start, add Locked = true and LockedReason = "Premium".

Popups

Ask before doing something with Confirm, or give your own buttons with Dialog.

Oblivion:Confirm({
    Title = "Unload?",
    Content = "The menu will close.",
    ConfirmText = "Unload",
    Callback = function()
        Window:Destroy()
    end,
})

Oblivion:Dialog({
    Title = "Choose",
    Content = "Pick one.",
    Buttons = {
        { Title = "Later", Callback = function() end },
        { Title = "Now", Variant = "Primary", Callback = function() end },
    },
})

Themes

Six built in: Mono (default), Moss, Midnight, Crimson, Ember and Rose. Switching is instant, even while the menu is open. Users can also pick one in the Settings tab.

Oblivion:SetTheme("Midnight")

-- or only change the accent colour
Oblivion:SetTheme({ Accent = Color3.fromRGB(0, 227, 255) })

Full example

Run this, then change it into your own script.

local Oblivion = loadstring(game:HttpGet("https://raw.githubusercontent.com/OSSDiablo/OblivionHub-UI/main/Source.luau"))()

local Window = Oblivion:CreateWindow({
    Name = "My Hub",
    Subtitle = "v1.0",
    ConfigurationSaving = { Enabled = true, FolderName = "MyHub" },
})

local Main = Window:CreateTab({ Name = "Main", Icon = "zap" })

Main:CreateSection("Movement")

Main:CreateSlider({
    Name = "Walk speed",
    Range = { 16, 100 },
    CurrentValue = 16,
    Flag = "WalkSpeed",
    Callback = function(Value)
        local Character = game.Players.LocalPlayer.Character
        local Humanoid = Character and Character:FindFirstChildOfClass("Humanoid")
        if Humanoid then
            Humanoid.WalkSpeed = Value
        end
    end,
})

Main:CreateToggle({
    Name = "Infinite jump",
    Flag = "InfJump",
    Callback = function(Value)
        print("Infinite jump", Value)
    end,
})

Main:CreateButton({
    Name = "Reset character",
    Style = "Danger",
    Callback = function()
        game.Players.LocalPlayer.Character:BreakJoints()
    end,
})

Oblivion:Notify({ Title = "My Hub", Content = "Loaded", Type = "Success" })

Window:LoadConfig()
